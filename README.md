# Chess Game with AI Engine

A responsive, feature-rich Chess web application built with React, TypeScript, Vite, and Tailwind CSS / custom modern styling.

## Features

- **Interactive Chess Board**: Smooth piece movement, legal move highlights, capture indicators, and check/checkmate alerts.
- **AI Opponent**: Minimax engine with Alpha-Beta pruning, evaluation heuristics, and configurable difficulty levels.
- **Evaluation Bar**: Real-time position evaluation showing material and positional advantage.
- **Move History**: Complete algebraic notation move list with step-through replay navigation.
- **Sound Effects**: Audio feedback for moves, captures, and checks.
- **Game Controls & Timers**: Configurable time controls with active chess clocks, flip board, undo/redo, and resign/draw options.

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Engine**: Chess.js with custom Minimax AI & Web Worker support
- **Styling**: Modern CSS with dark/light themes and responsive design

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

